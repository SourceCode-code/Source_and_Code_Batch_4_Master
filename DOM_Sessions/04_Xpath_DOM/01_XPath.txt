What is XPath?
XPath stands for XML Path Language.

//Absolute vs Relative XPath (15 mins)

| Absolute XPath                                                      | Relative XPath                                         |
| ------------------------------------------------------------------- | ------------------------------------------------------ |
| Starts from the root element (`/html`)                              | Starts from anywhere in the document (`//`)            |
| Uses the complete path from the root to the target element          | Uses attributes or relationships to locate the element |
| More fragile because any change in the page structure can break it  | More robust and flexible                               |
| Usually longer and harder to maintain                               | Shorter and easier to read                             |
| Slightly faster in theory, but the difference is usually negligible | Preferred in real-world automation                     |



Always prefer Relative XPath.
