#  Playwright Automation Framework

## Overview

This project is a scalable automation framework built using Playwright and TypeScript for end-to-end testing of web applications.

## 🛠 Tech Stack

* Playwright
* TypeScript
* Page Object Model (POM)
* Jenkins CI/CD
* HTML / Allure Reporting

##  Features

* End-to-End Test Automation
* API Testing Support
* Parallel Execution
* Reusable Page Objects
* CI/CD Integration

##  Project Structure

/tests → Test cases
/pages → Page Object files
/utils → Utility functions
/reports → Test reports

## ▶ How to Run

```bash
npm install
npx playwright test
```

* Reduced defect leakage by **30%**
